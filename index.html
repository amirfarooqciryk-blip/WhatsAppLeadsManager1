1. Import WhatsApp chat export

In WhatsApp, open a chat → ⋮ → More → Export chat → Without media. Select the exported .txt file here. For multiple chats, import each file separately.

This app does not connect to or read WhatsApp automatically. It only processes files you choose. The chat export may not include every contact number or all messages, depending on the export format.
